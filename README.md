# OOP Qt Shapes Project

## 📌 Projectomschrijving
Dit project is een **Qt/C++ applicatie** die verschillende **object-georiënteerde programmeerconcepten** demonstreert aan de hand van een grafische toepassing met vormen (Shapes).

De applicatie laat toe om **cirkels en rechthoeken** te creëren, tekenen en beheren via een **grafische gebruikersinterface (GUI)**.  
Het project is opgezet volgens **goede OOP-principes**, moderne C++ technieken en correcte Qt-architectuur.

---

## 🎯 Doelstellingen
Dit project demonstreert onder andere:

- Abstracte base classes
- Inheritance & polymorphism
- Object composition
- Constructor forwarding
- Dynamic memory management (`new` / `delete`)
- Modern C++ (const correctness, move semantics, lambdas)
- Qt concepts (signals/slots, threads, timers, containers)
- File I/O en exception handling
- Clean project structuur en onderhoudbare code

---

## 🖥️ Functionaliteit
- Grafische interface met knoppen
- Dynamisch aanmaken en verwijderen van shapes
- Polymorf tekenen via `Shape*`
- Asynchroon opslaan van logs (threaded)
- Automatische status-updates via signals/slots
- Veilige foutafhandeling (exceptions & nullptr checks)

---

## 🛠️ Gebruikte technologieën
- **C++17**
- **Qt 5.15+ / Qt 6**
- Qt Widgets
- QtConcurrent (threads)
- QSaveFile (modern file I/O)
